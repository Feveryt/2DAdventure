# ⚔️ 勇士传说 · Warrior's Legend

> **2D 横版动作跳跃游戏**

## 📖 项目简介

《勇士传说》是一款经典的 2D 平台动作游戏，玩家操控角色在像素风格的世界中探索、战斗。项目涵盖了完整的游戏循环：角色控制、敌人 AI、战斗反馈、UI 交互、音效管理及场景切换。

**Demo亮点**：
- 将敌人 AI 从 `if-else` 条件分支重构为**有限状态机（FSM）架构**，支持巡逻、追击、攻击等状态灵活扩展。
- 引入 **Addressables** 异步加载场景与敌人资源，降低运行时内存占用。
- 基于 **新版 Input System** 重构输入模块，实现按键映射与业务逻辑解耦。
- 利用 **C# 事件系统** 替代大量 `Update` 轮询，实现 UI、音效、角色状态间的松耦合通信。

---

## 🎮 核心玩法

- **移动与跳跃**：左右移动、跳跃、冲刺。
- **战斗系统**：近战攻击连击；敌人受击击退、闪烁无敌帧。
- **敌人 AI**：巡逻 → 发现玩家 → 追击 → 攻击 → 受伤 → 死亡，状态平滑切换。
- **关卡交互**：Tilemap 动态地形、陷阱、可破坏物体。
- **UI 与设置**：血量/体力 HUD、开始界面、音量/音效调节面板。
